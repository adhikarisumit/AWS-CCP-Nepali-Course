## कसरी पढ्ने — सुझाव

1. **हरेक मोड्युलको अन्त्यमा प्रश्नहरू छन्** — पढेपछि तुरुन्तै ती हल गर्नुहोस्। नगरी अर्को मोड्युल नजानुहोस्।
2. **AWS Free Tier मा account खोल्नुहोस्** — नयाँ account मा USD २०० सम्म credit पाइन्छ। EC2 launch गर्ने, S3 bucket बनाउने जस्ता काम आफैं गरेर हेर्नुहोस्। *पढेर मात्र होइन, गरेर सिकिन्छ।*
3. **सेवाको नाम र काम जोड्ने** — परीक्षामा अधिकांश प्रश्न "यो समस्याको लागि कुन सेवा?" भन्ने खालका हुन्छन्। त्यसैले हरेक सेवाको **एक-लाइन काम** कण्ठ पार्नुहोस्।
4. **Distractor चिन्नुहोस्** — AWS मा २००+ सेवा छन्। प्रश्नमा नचिनेको नाम आयो भने त्यो सायद झुक्याउनको लागि हो। तपाईंले सिकेको सेवामा ध्यान दिनुहोस्।
5. **अन्तिम २ दिन नयाँ केही नपढ्नुहोस्** — CHEATSHEET.md मात्र दोहोर्‍याउनुहोस्।

## खर्चको बारेमा चेतावनी ⚠️

अभ्यास गर्दा AWS मा पैसा लाग्न सक्छ। यी कुरा ध्यान दिनुहोस्:

- अभ्यास सकेपछि **EC2 instance terminate गर्नुहोस्** (stop मात्र होइन)।
- **Elastic IP** नचाहिए release गर्नुहोस् — प्रयोग नगरे पनि पैसा लाग्छ।
- **Billing Alarm** सुरुमै सेट गर्नुहोस् (मोड्युल १६ मा तरिका छ)।
- `t2.micro` इन्स्टान्स मात्र प्रयोग गर्नुहोस् — यो Free Tier मा पर्छ।
